Clean Cut: Samurai Duel — Privacy Policy

Last updated: November 21, 2026

Clean Cut: Samurai Duel ("the game") is published by Alexey Shipin. In short: the game works fully offline, collects nothing and sends nothing.

No account, no data collected

The game has no account or sign-in. We do not collect, receive, sell or share any personal data. The game has no internet permission and opens no network connection, so nothing can leave your device through it. It asks for no permission to read your contacts, location, camera, microphone, photos or files. The only permission it uses is vibration, for the haptic feedback of a cut.

Data stored on your device

This version stores no progress and no settings: every run starts fresh.

No ads

This version shows no ads and contains no advertising SDK. It does not use the Android advertising ID.

No in-app purchases

This version sells nothing.

No analytics or tracking

The game contains no analytics, crash-reporting or tracking SDK. Technical figures (such as the frame rate) are written only to the device's local system log for debugging and are not sent anywhere.

No notifications

The game does not send push or local notifications and does not ask for notification permission.

Children

The game shows stylized violence with blood and is intended for adults (18 and older). It is not directed at children and does not knowingly collect personal data from anyone.

Your choices

There is no data to manage. Deleting the app removes it completely.

Changes

If a future version changes how the game handles data (for example, if ads are added), this policy will be updated before that version is released, and the date above will change.
